# Security & Privacy Policy

The authoritative security policy for **Unified AI Workspace** is maintained at the root of the repository:

👉 **[View Root Security Policy](../SECURITY.md)**

### Key Highlights:
- **AES-256-GCM Credential Encryption:** Keys and OAuth tokens are encrypted before database insertion.
- **Minimal Read-Only Scopes:** Gmail and Drive access is strictly limited to read-only queries.
- **Zero Cloud Telemetry:** No user data or analytics are transmitted to third-party tracking services.
- **Vulnerability Reporting:** Report security issues privately via GitHub Security Advisories or to the repository maintainer.
